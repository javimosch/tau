Changelog

June 2026

⚔️

Author↔Critic Loop

Adversarial self-review via --role author|critic. Each role runs a full agentic tool loop with sentinel-based termination: <READY_FOR_REVIEW>, <APPROVED>, <BLOCKED>. Role-specific tool allowlists (author: read/write, critic: read-only).

🚁

Fleet Orchestration

Multi-agent work breakdown and dispatch. Coordinator LLM decomposes goals into work items with depends_on ordering. Sequential + parallel wave-based dispatch. Manifests persist to ~/.config/tau/fleets/. Subcommands: run, status, list, logs, cancel.

🎯

Goal Mode + Sessions

Autonomous work with /goal syntax. Agents can work toward objectives across multiple invocations with persistent session state.

📊

Token Tracking & API Usage

Real token usage parsed from OpenAI-compatible API responses (usage.total_tokens). Fallback to content-length approximation. Wired through agent.run(), Author↔Critic loop, and fleet workers.

🧪

Quality Hardening

Unit tests for extractUsage API parser (happy path, null, overflow, missing), Manifest JSON round-trip test, expanded smoke suite to 59 tests covering --role flag, fleet subcommands, and all tools.

📡

Streaming + ACP

Real SSE token-by-token streaming. Agent Client Protocol (ACP) support: stdio server, daemon management (start/stop/status/serve), session persistence, tool loop streaming, and cross-platform support.
