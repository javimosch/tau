Agent-First
AI CLI

Non-interactive Zig reimplementation of pi. Built for AI agents, not humans.

Get Started Learn More

What You Get

Everything agents need, nothing they don't.

Tool-Calling Loop

Model calls tools automatically. Results fed back until final answer. 7 built-in tools: bash, read, write, edit, ls, grep, find.

--tools bash,read

JSON by Default

Deterministic structured output. Add --mode text for human-readable.

Goal Mode

Autonomous work until complete. /goal objective syntax.

Sessions

Persistent conversation + goal state across invocations.

Context Compaction

LLM summarization at configurable threshold.

Architecture

Built for determinism, not convenience.

Non-Interactive Only

No TUI, no prompts, no hidden retries. Every invocation is deterministic and scriptable.

Semantic Exit Codes

0 success, 80 invalid arg, 82 missing field, 105 timeout, 106 auth failed, 110 internal. Scripts and agents handle failures deterministically.

Streaming Support

Real SSE token-by-token streaming. Text mode: raw deltas. JSON mode: NDJSON chunks.

Provider Abstraction

xiaomi (default), openai, deepseek. All speak OpenAI chat-completions wire format.

Quick Start

zig build
./zig-out/bin/tau "What is Zig?"
./zig-out/bin/tau --tools bash,read "Analyze the codebase"
./zig-out/bin/tau --session project "/goal add tests"
